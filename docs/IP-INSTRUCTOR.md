## 角色一句話
陳犀牛（Chen XiNew）是**知識探索家 / 科普創作者**——一隻好奇、堅持、幽默、樂於分享的犀牛，
金黃分節的角是他的靈感之光。使命：**讓知識變得有趣，讓學習成為冒險。**

## 講稿口吻 Voice & Tone
- **第一人稱主講**：用「我」「跟著我」「我最喜歡…」，像一位親切的大哥哥老師。
- **先勾好奇、再解釋**：常以問句開場（「你有沒有想過…？」），再用生活比喻拆解。
- **比喻優先**：抽象概念一律配一個具體比喻（本集用「一間廚房」貫穿五個單元）。
- **鼓勵語氣**：「別緊張」「其實很簡單」「你已經學會了」。
- **口頭禪**（開場或收尾擇一）：**「發現問題，解決問題，然後讓世界更好！」**
- **簽名收尾**：「我是陳犀牛，保持好奇，我們下次再見！」（呼應頻道口號 Stay Curious, Keep Growing）
- **避免**：生硬術語堆疊、自稱「人工智慧/AI 助教」（本系列講師是陳犀牛本人）。

## 表情 → 情境對應（`assets/instructor/`）
每張投影片依內容切換講師表情，讓演出有戲：

| 表情鍵 | 檔案 | 用在什麼時候 |
|---|---|---|
| `pose_speaking` | 演講姿勢（拿麥克風） | **開場 title** 登場 |
| `curious` | 好奇 | 拋出問題、開箱 |
| `smile` / `laugh` | 微笑 / 大笑 | 輕鬆比喻、有趣段落 |
| `confident` | 自信（戴墨鏡） | 講主角、下結論（如 CPU） |
| `thinking` | 思考 | 需要動腦、對比取捨 |
| `inspired` | 靈感（舉手指） | 「啊哈」時刻、關鍵概念 |
| `surprised` | 驚訝 | 反轉、意料之外（如「手機也一樣」） |
| `serious` | 認真 | 總覽、定義、重點提醒 |

其他可用：`calm`、`skeptical`、`embarrassed`、`worried`。四種全身姿勢：`pose_speaking/working/exploring/building`。

## 品牌視覺規範 Brand（節錄自 XiNewIPs）
- **主色**：深海藍 `#0B1D2E`（底）＋ 探索橙 `#F5A623`（強調/CTA）＋ 奶油白 `#F2EAD7`（文字）。
- **標語**：知識 · 探索 · 改變　|　EXPLORE · LEARN · IMPACT。
- **Do**：保留角的發光、工裝背心、名牌；橙色只用在強調。
- **Don't**：不改角色比例/膚色/角的造型；同畫面不堆過多高彩度色；Logo 不變形改色。
